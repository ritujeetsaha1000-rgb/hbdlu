# Lucy's Sweet 16th Birthday Web App 🎂💖

A customized, mesmerizing birthday surprise web application made for Lucy's 16th Birthday (Born: October 26, 2010).

## ✨ Features
1. **Mesmerizing Aesthetic:**
   - Floating romantic hearts background
   - Glassmorphic pastel cards, elegant serif typography, rose gold accents
   - Interactive background melody chime synthesizer (Web Audio API)
2. **Our Love Story Timeline:**
   - **30th June:** Meeting from the train station when she was in her school uniform
   - **Through Conflicts & Storms:** Fighting for each other and growing unbreakable
   - **11th September (11:11 PM):** The magical wish proposal
   - **26th October:** Sweet 16th Birthday celebration
3. **Interactive Polaroid Memory Gallery:**
   - Click to zoom and admire each special memory
4. **Interactive Birthday Notes:**
   - Tap envelopes to reveal heartfelt love letters
5. **The Runaway "Do You Love Me?" Arena:**
   - Features mobile-optimized touch evasion (`touchstart`, `pointerdown`, `pointerover`)
   - On her mobile phone, whenever she tries to tap "No", the button dodges her finger, displays playful taunts, and expands the "YES" button!
   - She **cannot** click "No"!
6. **Surprise Unboxings:**
   - **Surprise #1:** Plays your funny "cringe vdo of us" with unboxing effects
   - **Surprise #2 (Grand Finale):** Unlocks the "fab vdo of us" with golden star confetti fireworks & final letter

## 🚀 How to Deploy on Vercel in 2 Minutes

### Method 1: Deploy with GitHub & Vercel Dashboard (Recommended)
1. Initialize a Git repository in this folder:
   ```bash
   git init
   git add .
   git commit -m "Happy Birthday Lucy"
   ```
2. Create a new repository on GitHub (e.g. `lucy-birthday`) and push:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/lucy-birthday.git
   git branch -M main
   git push -u origin main
   ```
3. Go to [vercel.com](https://vercel.com) and click **"Add New..."** -> **"Project"**.
4. Import your `lucy-birthday` repository.
5. Vercel will automatically detect the static project. Click **"Deploy"**!
6. In ~15 seconds, you will get your live link (e.g., `https://lucy-sweet16.vercel.app`) to send to her!

### Method 2: Instant Local Preview
Simply double click `index.html` or open with any browser on your computer.
